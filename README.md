# Sameera's Authentic Kitchen 🌿🍲
> **Pure • Traditional • Homemade**

A complete, fully functional, responsive modern web application built with **React.js** and **Vite** for **Sameera's Authentic Kitchen**, a homemade traditional South Indian food business based in **Srirampura, Mysore, Karnataka, India**.

Showcases handcrafted pickles, authentic Mysore-style Puliyogre Gojju, instant dosa flours, and seasonal festive delicacies such as Sankranti Sakkare Acchu, Yellu Bella, and Aralu Sandige.

## 💻 Local Development Setup

To run this application locally:

```bash
# 1. Install dependencies
npm install

# 2. Start the development server
npm run dev

# 3. Create a production build
npm run build

# 4. Preview the production build locally
npm run preview
```

## 🌐 Deployment to GitHub & Vercel

### Step 1: Initialize Git and Push to GitHub
```bash
git init
git add .
git commit -m "Initial commit: Complete Sameera's Authentic Kitchen React.js Website"
git branch -M main
git remote add origin https://github.com/<your-username>/sameera-authentic-kitchen.git
git push -u origin main
```

### Step 2: Deploy to Vercel
1. Go to [https://vercel.com](https://vercel.com) and log in with your GitHub account.
2. Click **"Add New"** > **"Project"**.
3. Import the `sameera-authentic-kitchen` repository.
4. Verify project settings:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **"Deploy"**.
6. Your website will be live with a free SSL-secured `.vercel.app` domain!
